¿Cómo debe organizarse la navegación del panel admin?

Irving va a usar esto diario para gestionar productos, pedidos y suscriptores

A — Sidebar de íconos (colapsado)

Sidebar estrecho con solo íconos. Máximo espacio para el contenido. Ideal en pantallas pequeñas o laptops. Irving hace hover para ver el nombre de cada sección.

B — Sidebar expandido con texto

Sidebar fijo con ícono + etiqueta visible siempre. Navegación clara sin necesidad de memorizar íconos. El estándar de la mayoría de admin panels (Shopify, Stripe).

C — Topbar horizontal

Navegación en la barra superior. Más espacio vertical para tablas y listas de productos. Común en herramientas más simples, menos secciones visibles de golpe.
